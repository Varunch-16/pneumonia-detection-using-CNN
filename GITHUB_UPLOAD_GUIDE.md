# GitHub Upload Commands

After downloading this cleaned project folder, open Command Prompt or VS Code terminal inside the folder and run:

```bash
git init
git add .
git commit -m "Initial commit: pneumonia detection Flask app"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/pneumonia-detection-efficientnetb0.git
git push -u origin main
```

Before running the remote command, create a new empty repository on GitHub named:

```text
pneumonia-detection-efficientnetb0
```

Do not initialize the GitHub repository with a README because this project already includes one.
