# Training Experiments

This folder contains the original experiment scripts and saved result outputs for the four transfer-learning models used in the study:

- EfficientNetB0
- DenseNet121
- ResNet50
- VGG16

The final deployed application uses the saved EfficientNetB0 H5 model located at `model/new.h5`.

The original scripts may contain local Windows dataset paths from the 2024 training environment. They are kept here for reference and reproducibility documentation, but running the Flask app does not require retraining.
