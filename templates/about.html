About the Project

Making chest X-ray classification easier to understand.

PneumoScan is an academic deep learning project built to classify chest X-ray images as Normal or Pneumonia using an EfficientNetB0-based model.

What this project does

The project allows a user to upload a chest X-ray image through a simple web interface. The backend preprocesses the image, sends it to the trained model, and displays the predicted class on a result page.

The goal is to demonstrate how deep learning can be connected with a usable web application, not to replace doctors or radiologists.

Model comparison

Several pre-trained CNN models were compared, including ResNet50, DenseNet121, VGG16, and EfficientNetB0. EfficientNetB0 was selected for the final application because it performed strongly in the project evaluation.
